## 6. Recommendation playbook

Use these when the data shows the pattern in the left column. Every recommendation is a **hypothesis**: test it (Adobe Target A/B test, or before/after with the same KPI) before rolling it out.

### Navigation

| If the data shows… | Then consider… | Measure with |
| --- | --- | --- |
| A submenu item (e.g. *Seasonal Offers*, *Picked for You*) is in the bottom 3 for two periods | Move it lower, merge it, or promote it on the home page instead | Item CTR, total Nav CTR |
| *Deals* or *Rewards* (top level) outperform the Shop submenu items | Keep high-intent links at the top level; test adding the top department as a top-level link | Nav clicks on that item, department page views |
| Mobile Nav CTR is much lower than desktop, and many `menu-open` events have no click after them | The mobile menu is hard to scan: shorten labels, open *Shop* by default, add the top departments as quick links | Mobile Nav CTR, clicks per `menu-open` |
| Many nav clicks from one page (e.g. product pages) | That page lacks onward links: add related-department or "continue shopping" links in the page | Nav CTR on that page, page exits |
| Search-engine visitors use the nav much less than direct visitors | Landing pages need clear in-page next steps; nav alone doesn't guide new visitors | Nav CTR by traffic source, bounce rate |
| *Help* items get many clicks | Visitors have recurring problems: check which help pages and fix the root cause (FAQ, delivery info) | Help clicks per visit |

### Login and signup

| If the data shows… | Then consider… | Measure with |
| --- | --- | --- |
| Login Success Rate below ~85 % or a sudden drop | Check error causes (wrong password vs server errors), add "show password", clearer error text, password reset link | Login Success Rate, Login Failures |
| Mobile login success clearly lower than desktop | Check autofill (`autocomplete` attributes), keyboard type for email, button visibility | Success rate by device |
| Many signup starts, few completions | Shorten the form, remove optional fields, show password rules upfront, save progress | Signup Completion Rate |
| Login clicks far exceed signup clicks on the same pages | Add a visible "New here? Create an account" next to sign-in, with a benefit (Rewards points) | Signup Clicks on those pages |
| Header dropdown logins succeed more often than the full page | Promote the dropdown entry point, or align the full-page form with it | Success rate by location |
| Login activity peaks on cart/checkout pages | Offer guest checkout plus "sign in to use your points", to avoid forcing login | Checkout conversion, login clicks on checkout |

### Departments

| If the data shows… | Then consider… | Measure with |
| --- | --- | --- |
| A department has a low CTR on the Shop page cards | Test a stronger image, a clearer CTA ("Shop 8 headphones"), or moving the card first | Department CTR |
| High page views but low scroll 75 % reach | Key products are too far down: move best sellers up, shorten the hero, reduce banners above the grid | Scroll 75 % Reach, Department Card Clicks |
| High scroll but few card clicks | Visitors look but don't find: improve product titles and images, show prices and badges clearly | Department CTR on product grid |
| Filters are used often on one department | Visitors need help narrowing down: make the most-used filter a visible quick filter (chip) | Filter uses, card clicks after filtering |
| One department has a much lower engagement rate | Review its content (guides, tabs, banners) against the best department, and copy what works | Engagement Rate per department |
| Many visitors leave after the Shop page (flow) | The department cards don't match intent: add search and popular categories higher up | Exit rate on Shop |

## 7. Appendix

### Definitions

| Metric | Definition |
| --- | --- |
| Top Navigation Clicks | Clicks on header links (brand, sections, submenus, tools). Search and sign-in forms are excluded |
| Nav CTR | Top Navigation Clicks ÷ Page Views |
| Login Success Rate | Login Successes ÷ (Login Successes + Login Failures) |
| Login Conversion Rate | Login Successes ÷ Login Clicks |
| Signup Conversion Rate | Signup Completions ÷ Signup Clicks |
| Department CTR | Department Card Clicks ÷ Department Impressions |
| Engagement Rate | Visits with ≥ 50 % scroll or ≥ 10 active seconds ÷ all visits |
| Avg Active Seconds per Page View | Active seconds (tab visible, visitor active in the last 30 s) ÷ Page Views |
| Scroll 75 % Reach | Page views that reached 75 % of the page ÷ Page Views |
| Time Spent per Visit | Adobe's standard metric; it can't measure the last page of a visit, so compare with active seconds |
